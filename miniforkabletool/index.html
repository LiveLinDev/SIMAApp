Cómo funciona

            
La herramienta analiza tu JSON en 4 pasos para producir un fork robusto.

          

        

        

          

            
Busca el array de registros
Recorre el JSON recursivamente y selecciona el array de objetos más denso (más filas × más campos), ignorando wrappers como success o message.

            
Infieres tipos y anidaciones
Para cada campo detecta si es string, number, boolean, array u objeto. Si es array de objetos, infiere si tiene patrón key+text, text+correct, u otro.

            
Elige estrategia de serialización
Primitivos van directo. Arrays de objetos se aplanan a K:valor;K:valor o JSON escapado. Objetos anidados se aplanan si tienen ≤3 campos.

            
Genera prompt + ejemplo real
El prompt incluye gramática exacta, mapeo campo a campo, reglas de escaping, y un ejemplo convertido desde tus datos reales — no valores inventados.
